# ДЗ 8. Разновидности кирпичей

Прочные кирпичи выдерживают три удара и меняют цвет. Стеклянные пропускают мяч после попадания.

## Сборка и запуск

Откройте `Game.sln` в Visual Studio 2022 с компонентом «Разработка классических приложений на C++». Выберите Release x64, соберите решение и нажмите Ctrl+F5. Библиотеки SFML и игровые ресурсы доступны в репозитории.

После сборки папка `ArkanoidGame/x64/Release` содержит исполняемый файл, DLL и ресурсы. Запускайте `ArkanoidGame.exe` с рабочим каталогом этой папки.
